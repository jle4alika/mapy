# Выбор карты и офлайн-режим

## Решение

Клиент (React Native / Expo web): **MapLibre GL** в WebView/iframe.

Онлайн-подложка: **кастомные темы** на **OpenFreeMap Liberty** (OSM) — с POI/точками как на обычной карте, **без API-ключа**. Zoom POI снижен (с ~11–13), чтобы кафе/магазины/транспорт были видны раньше.

У Blink в проде сейчас свои **Blink Maps** (своя 3D-платформа; раньше Apple/Google). Мы не копируем их движок — делаем свою soft-social тему в духе их визуала: пастель, вода/cyan, спокойные дороги, меньше шума.

Опционально: `EXPO_PUBLIC_MAP_STYLE_URL` или `EXPO_PUBLIC_MAP_TILES_URL`.
Офлайн: пакеты региона **MBTiles**/PMTiles по манифесту с сервера.

## Почему не другие варианты

| Решение | Минус для нашего продукта |
|---------|---------------------------|
| Яндекс MapKit | Офлайн только на платной лицензии; нет официального React Native |
| 2ГИС | Офлайн через продажи; закрытый каталог |
| Google Maps | Слабый контролируемый офлайн; квоты |
| Mapbox / MapTiler / Stadia | Нужен API-ключ |
| Сырой `tile.openstreetmap.org` | Слишком детальный; политика использования |

## Роль сервера

Сервер **не рисует** карту. Он отдаёт позиции друзей, места, чаты, манифест офлайн-пакетов, приватность гео.
