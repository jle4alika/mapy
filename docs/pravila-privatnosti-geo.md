# Правила приватности геолокации

## База

- Гео видят только **взаимные** друзья.
- Блок скрывает обе стороны.
- Настройки профиля: `share_precise_location`, `share_battery`, `share_speed`.

## Режимы на конкретного друга (`friend_visibility_overrides`)

| mode | Что видит друг |
|------|----------------|
| `normal` | Точные координаты (если разрешено профилем) |
| `frozen` | Снимок lat/lon на момент включения; режим **не** раскрывается зрителю |
| `approximate` | Смещённая точка внутри радиуса; `accuracy_mode=approximate` |

Срок максимум **24 часа** (`expires_at`). Истёкшие строки чистит Celery-задача `maintenance.expire_visibility_overrides`.

## Approximate: стабильность

Смещение детерминировано от пары `(owner_id, viewer_id, календарный день)`, чтобы точка не прыгала на каждом кадре.

## Stale

Если долго нет обновлений — `accuracy_mode=stale` (клиент может затемнить пин).
